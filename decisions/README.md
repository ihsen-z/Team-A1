# Décisions d'architecture (ADR)

Un fichier par décision structurante, numéroté, jamais réécrit : une décision
remplacée est marquée « Remplacée par NNNN », pas effacée.

Sert deux usages :
- quand un client veut évoluer dans 18 mois, retrouver **pourquoi** ;
- donner aux agents le contexte des choix, pour qu'ils ne les contredisent pas.

Format : Contexte · Décision · Alternatives écartées · Conséquences.

Le chef de projet (`/kickoff`) écrit un ADR par projet client sur le choix de
stack. Les décisions transverses (celles-ci) sont écrites à la main.
