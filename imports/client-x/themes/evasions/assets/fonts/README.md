# Polices

Auto-hébergées (sous-ensemble latin, polices variables, format WOFF2) :

| Fichier | Famille | Graisses | Licence |
|---|---|---|---|
| `manrope-latin.woff2` | Manrope | 500 à 800 | SIL Open Font License 1.1 |
| `dm-sans-latin.woff2` | DM Sans | 400 à 700 | SIL Open Font License 1.1 |
| `dm-sans-italic-latin.woff2` | DM Sans italique | 400 à 700 | SIL Open Font License 1.1 |

Source : Google Fonts (fonts.gstatic.com), version Manrope v20 et DM Sans v17. Les
licences OFL autorisent l'hébergement et la redistribution avec le thème.

Le sous-ensemble **latin** couvre le français en entier (accents, œ, « », €).
Un caractère hors de ce sous-ensemble s'affiche dans la police système. L'arabe
n'est fourni par aucune de ces deux familles : il utilise la police système,
comme avant. Les règles `@font-face` sont en tête de `../css/main.css`.
